# 判定口径与通过率模型

## 一、五级分层

按《商标审查审理指南》文字近似的四要素判定：字形、读音、含义、整体外观。

| 层级 | 判定标准 | 障碍强度 | 处理方式 |
|---|---|---|---|
| A 相同 | 文字完全相同，无附加要素 | 决定性 | 存在有效在先注册即基本阻断，不再评估后续因子 |
| B 含全称 | 完整名称外加持字母、英文或图形的变体，主体识别仍指向同一来源 | 高 | 评估附加要素是否足以区分来源 |
| C 同构 | 保持与原商标相同的字数结构与节奏，仅替换首字，读音或字形接近 | 中高 | 首字同音风险最高，字形差异可降级 |
| D 核心词 | 含原商标的核心词，前后有实质性限定词 | 低 | 用于排除大面积撞车，影响服务项目选择 |
| E 前缀 | 仅前两字相同，整体含义已分化 | 低 | 备查，不构成实质障碍 |

判定顺序从上到下，每件商标归入唯一层级，不重复计数。

## 二、状态过滤

| 状态 | 是否构成在先权利 | 计数规则 |
|---|---|---|
| 已注册（在有效期内） | 是 | 计入有效障碍 |
| 申请中 | 是（在先申请） | 计入有效障碍，标注在审 |
| 已注册但已过有效期未续展 | 否 | 计入无效 |
| 已无效、驳回、撤回、注销 | 否 | 计入无效，仅作审查尺度参考 |

无效件单独统计，不得与有效件合并成障碍数量。报告里要写明「另 N 件已无效，不构成在先权利」。

## 三、通过率模型

不输出单一百分比，按申请主体拆分场景。

### 场景划分

| 场景 | 定义 | 判定要点 |
|---|---|---|
| A 非关联主体新申请 | 申请人与在先注册人不是同一主体，也未获授权 | 存在相同有效注册即为决定性阻断 |
| B 关联主体补充申请 | 申请人与在先注册人为同一集团或已获授权，补充未覆盖的服务项目 | 自有注册不构成障碍，改看外部近似密度 |
| C 关联主体扩类 | 同一主体向其他类别扩展 | 逐类核查在先障碍与类似群交叉 |

### 区间算法

1. 先查有无相同有效注册。有，场景 A 直接落到 5% 以下，不再计算其他因子。
2. 场景 B 以基础值 78% 起算，按下面因子加减，最终收敛在 75%—88%：
   - 外部同构有效注册每 5 件，扣 1 个百分点，最多扣 6
   - 存在读音仅差声调的在审件，扣 2
   - 商标为成语、通用词或描述性词汇，扣 3
   - 商标为非成语的独创组合，加 3
3. 场景 C 以 62% 起算，每发现一件同类别有效近似扣 3，最低 55%。

结果取整到 5 的倍数，给区间而不是单点。

### 校准

用同构族的历史核准率约束上限，不要凭感觉给数。

计算方式：取同结构商标在该类别的全部申请记录，统计「已注册」占比，作为该结构的经验核准率。

示例：35 类「X 思妙想」共申请 30 件、核准 12 件，核准率约 40%。此时场景 B 上限不得高于 85%。

样本少于 10 件时不作校准，报告注明样本不足。

## 四、因子权重

| 因子 | 权重 | 说明 |
|---|---|---|
| 在先相同商标（有效） | 决定性 | 成立即阻断，其余因子不再拉升结论 |
| 高度近似密度 | 高 | 同构、首字同音的有效件数量 |
| 服务项目类似群交叉 | 高 | 同类别不同类似群不构成类似服务，未细分时是最大不确定项 |
| 商标显著性 | 中 | 成语、通用词、描述性词汇显著性弱 |
| 在先中近似（核心词相同） | 中 | 影响服务项目选择，不直接驳回 |
| 图形近似 | — | 纯文字申请不适用；图文组合须另行评估 |

## 五、必须写进报告的边界

- 只做文字检索，不含图形近似比对
- 不含具体服务项目与类似群判定，需要知产人员人工确认
- 通过率为经验估算，不构成商标局审查结论
- 不构成注册成功承诺，不得用于对外报价

## 六、常见误判

| 误判 | 正确做法 |
|---|---|
| 把「奇思妙想」等同构商标当作必然障碍 | 先看状态，35 类历次申请均无效时它不构成在先权利 |
| 认为同类别就一定构成类似服务 | 35 类分 3501—3509 九个类似群，需逐群比对 |
| 关联主体与自有注册冲突也判为阻断 | 同主体自有注册不是障碍，要看是否存在服务项目重叠 |
| 用单一百分比回答 | 必须拆场景，两个场景可能差一个量级 |
