# 商标注册通过率评估

用户要一个结论：这个商标能不能注册、概率多少。按下面的流程走完，输出一页纸的 HTML 与 PDF。

## 一、解析参数

触发句式包括「帮我查：XXX商标的注册通过率」「XXX 能注册吗」「帮我评估 XXX 商标」。

必须凑齐三项：

| 参数 | 来源 | 缺失时 |
|---|---|---|
| 商标名称 | 从用户原话中取 | 必须问 |
| 公司名称 | 用户原话中的申请主体 | 必须问 |
| 商标类别 | 用户原话中的第 N 类 | 必须问 |

原话里已经给出的不再重复问。一次问完，合并成一次提问，不要分两轮。用户只说了商标名时，用 AskUserQuestion 把公司名称和类别放在同一组问题里。

类别只收纯数字，如 35、42。「35类」归一化为 `35`。

## 二、OA-MCP 预检

检索前必须先做一次最小调用，确认工具可用、权限正常、数据能返回。

调用 `mcp_oa-mcp_oa_es_trademark_base_search`，参数 `{"keyword":"<商标名称>","page_size":5}`。

按下表判定，不要跳过：

| 返回情况 | 处理 |
|---|---|
| 工具不存在、调用报错、超时 | 停止检索，提示检查 OA-MCP 配置 |
| 返回 `UNAVAILABLE`、权限或数据范围错误 | 停止检索，提示权限问题 |
| `SUCCESS` 且 `data.items` 非空 | 继续检索 |
| `SUCCESS` 但 `items` 为空 | 换前两字再试一次；仍为空则按「未检索到近似」继续 |

提示配置问题时要给到具体动作，不要只说「请检查配置」：

- OA-MCP 服务是否已连接、地址是否可达
- 身份凭证是否过期
- 数据范围是否为经理及以上
- 商标基础索引接口是否在授权清单内

修好后让用户回一句「继续」，再接着跑。

## 三、四轮检索

每轮 `page_size=100`，翻页到 `has_more=false` 为止，不能只取第一页。

| 轮次 | 关键词 | 用途 |
|---|---|---|
| 1 | 商标全称 | 锁定完全相同与含全称的变体 |
| 2 | 前两字 | 同主体防御注册、近似前缀 |
| 3 | 核心词（显著性强的一段） | 「X+核心词」同构族群 |
| 4 | 商标全称，不限类别 | 全类布局与权利主体核查 |

按 `tid` 去重，形成唯一记录池。

## 四、分层与评估

按 A—E 五级分层，再按申请主体拆场景算通过率。

判定口径、障碍强度换算、通过率模型、校准方法全部在 `references/rules.md`，执行前先读它。

三条硬约束：

- 已无效的商标不计入在先权利，不能当作障碍
- 相同商标在有效期内即为决定项，其余因子不再拉升结论
- 服务项目类似群未细分时，必须在报告里标注为最大不确定项

## 五、生成报告

1. 把评估结果写成 JSON，字段照 `assets/report_template.html` 里的占位符一一对应，缺一个脚本会报错。
2. 运行：

```bash
python scripts/build_report.py --data <数据.json> --out <输出目录>
```

3. 脚本输出 HTML 与 PDF 两个文件，文件名形如 `商标注册通过率评估-企思妙想-35类.html`。
4. 在回复里用 `computer://` 链接交付，同时用一句话给出结论。

JSON 结构：

## 六、交付前自检

- 四轮检索都已翻到 `has_more=false`
- 相同商标的有效期与续展状态已核对
- 无效件单独计数，没混进障碍
- 通过率标注为经验估算，没有任何注册成功承诺
- HTML 与 PDF 都已生成，PDF 为一页

## 常见问题

| 现象 | 原因 | 动作 |
|---|---|---|
| PDF 变成两页 | 内容超一页 | 精简障碍行或说明文字，不要改版式 |
| 中文路径导致 PDF 失败 | URI 未编码 | 脚本已处理，不要手工改路径 |
| 检索结果为 0 | 关键词过窄或库内无记录 | 换前两字重试，报告注明「未检索到近似」 |
| 用户要图形商标 | 本技能只做文字检索 | 明确说明不含图形近似，建议人工复核 |
